Personal portfolio of **Muhammad Taqi Abbas**, Biomedical Engineer & AI Researcher (Lahore, Pakistan).

**Live site:** https://muhammadtaqi811.github.io/My-Porfolio/

## What's inside

- `index.html` — the whole site (one page, no build step)
- `assets/img/` — portrait and exoskeleton prototype photos
- `assets/docs/` — downloadable CV and transcript (CNIC hidden on the transcript)

## Editing

Open `index.html` in any text editor, change the text, then commit and push. GitHub Pages republishes the site automatically within a minute or two.
